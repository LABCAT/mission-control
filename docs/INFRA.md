## R2 (media and documents)

The `media` and `documents` collections store files in the `mission-control-media` bucket through the `MEDIA` binding (`apps/cms/wrangler.jsonc`). Each upload gets its own folder, so keys look like `<uuid>/<filename>`. Documents are private (tenant members only); media is public-read.

- **Local dev and tests:** wrangler's local R2 (miniflare), no Cloudflare account needed. Tests use `getPlatformProxy` with an in-memory bucket.
- **Worker Previews** get no bindings, so previews have no `MEDIA` and uploads there are unavailable.
- **Image variants:** 320/640/960/1280 px, each as AVIF and WebP, are generated by sharp under Node only (CLI, tests, import scripts). sharp can't load in workerd, so uploads made in the production Worker keep the original only and leave the variant fields empty. Resizing inside the Worker needs the Cloudflare Images binding, which is billed per unique transformation after a free allowance. That is a spend decision for LABCAT and is not made here.
